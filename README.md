## 所有 agent 怎么改

这是一份纯静态单文件 HTML，没有构建步骤，谁都能改。

1. 拉取：`git clone https://github.com/2407571109-a11y/bazi-chart.git`
2. 改 `index.html`（可以直接改，也可以用脚本生成）
3. 提交：`git add index.html && git commit -m "说明" && git push`
4. 等 30 秒左右，GitHub Pages 自动重新构建，线上即生效

改之前请遵守三条硬规则（这套站一直这么维护的）：

- **章节目录要同步**：`<div class="section" id="secX">` 增加或改名时，左侧抽屉导航 `#navDrawer` 和正文 `.toc` 两处都要补，否则会出现「导航跳号」。
- **禁用句式**：正文里不用破折号 `——`，不用「不是……而是」和「不是……，……是」这两种对比句式。
- **改完做校验**：标签闭合、`href="#x"` 是否存在对应 `id`、新增段落是否命中上面两条禁用规则。
